Agent-Driven UI inspectora2ui/0.1 · ag-ui event stream
Esta pantalla no está programada a mano: el agente emite este JSON declarativo y un renderizador con componentes permitidos la monta. Cambia el spec, cambia la UI.

  
Cada control lleva un token semántico con significado propio. En vista Arquitecto aparecen sobre los propios controles.

  
Sincronización bidireccional: cada toque emite un evento tipado de vuelta al agente, que decide el siguiente spec.

  
Al reservar, este prototipo entrega un payload estructurado a la app externa de citas. No reconstruye esa app: solo demuestra el handoff.
